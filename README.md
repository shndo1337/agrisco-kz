# AgriScore KZ

**AI-система скоринга сельхозпроизводителей для merit-based распределения субсидий**

> Хакатон Decentrathon 5.0 | Трек AI inDrive | Кейс 2

---

## Проблема

Сегодня государственные субсидии для сельхозпроизводителей Казахстана распределяются по принципу **«первый подал — первый получил»**: финансирование уходит тому, кто раньше собрал пакет документов, пока не закончился бюджет. Реальная эффективность хозяйства, история использования предыдущих субсидий и потенциал к росту **не учитываются**.

Министерство хочет перейти к **merit-based скорингу** — распределению субсидий на основе данных о производителях, а не по принципу очерёдности.

## Решение

AgriScore KZ — AI-система, которая заменяет принцип очереди на **data-driven ранжирование**:

- **Скоринг заявителей** — каждая заявка получает балл от 0 до 100 на основе ML-модели, обученной на исторических данных
- **Explainability** — для каждого балла система объясняет, какие факторы повлияли и почему (SHAP-анализ + текстовое объяснение на русском языке)
- **Шорт-лист для комиссии** — автоматическое формирование списка лучших кандидатов с возможностью экспорта
- **Аналитический дашборд** — визуализация распределения баллов по областям, направлениям, статусам

> AI помогает принимать решения, но **не заменяет эксперта**. Финальное решение всегда остаётся за комиссией.

## Данные

- **Источник**: Выгрузка из ИСС (subsidy.plem.kz) — 36,651 заявок на субсидии племенного животноводства за 2025 год
- **Области**: 18 областей Казахстана
- **Направления**: 9 направлений (скотоводство, птицеводство, овцеводство, коневодство, верблюдоводство и др.)
- **Типы субсидий**: 45+ видов субсидий
- **Target**: статус заявки (Одобрена/Исполнена vs Отклонена)

### Engineered Features

| Признак | Описание |
|---------|----------|
| `log_amount` | Логарифм суммы субсидии |
| `log_normative` | Логарифм норматива на голову |
| `animals_count` | Расчётное количество голов (сумма / норматив) |
| `normative_tier` | Класс норматива (0–4, отражает ценность поголовья) |
| `is_breeding` | Флаг: племенная работа |
| `is_import` | Флаг: импортное поголовье |
| `is_milk / is_meat / is_poultry` | Флаги направления продуктивности |
| `is_purchase / is_feed` | Флаги типа субсидирования |
| `oblast_enc / direction_enc / district_enc` | Закодированные географические и отраслевые признаки |
| `month / hour` | Временные признаки подачи заявки |

## Explainability

Каждая заявка получает три уровня объяснения:

**1. Числовой балл** (0–100) — нормализованная вероятность одобрения

**2. SHAP waterfall-диаграмма** — визуальный вклад каждого фактора:

![SHAP](https://img.shields.io/badge/SHAP-Explainability-green)

**3. Текстовое объяснение** на русском языке:
```
Итоговый балл: 98.0/100

Положительные факторы:
  + Область (+1.298)
  + Тип субсидии (+1.213)
  + Район хозяйства (+0.479)
  + Норматив на голову (+0.225)
  + Количество животных (+0.214)
Факторы риска:
  (отсутствуют)
```

## Метрики модели

| Метрика | Значение |
|---------|----------|
| ROC-AUC | 0.853 |
| Accuracy | 0.78 |
| F1 (Одобрена) | 0.86 |
| Recall (Отклонена) | 0.76 |

> Модель обучена на 31,536 размеченных заявках (28,627 одобренных / 2,909 отклонённых). Дисбаланс классов учтён через `scale_pos_weight`.

## Ограничения

- Датасет обезличен — нет индивидуального ID производителя, что ограничивает возможность агрегации истории по конкретному заявителю
- Модель обучена на данных 2025 года — для продакшена потребуется периодическое дообучение
- Текущая версия использует только ML-скоринг; в следующих версиях будет добавлен rule-based компонент на основе нормативных документов
- Система носит **рекомендательный характер** — финальное решение всегда за комиссией
