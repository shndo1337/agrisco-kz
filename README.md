# AgriScore KZ

**AI-система merit-based скоринга сельхозпроизводителей для распределения субсидий**

> Хакатон Decentrathon 5.0 | Трек AI inDrive | Кейс 2

---

## Проблема

Сегодня государственные субсидии для сельхозпроизводителей Казахстана распределяются по принципу **«первый подал — первый получил»**: финансирование уходит тому, кто раньше собрал пакет документов, пока не закончился бюджет. Реальная эффективность хозяйства, история использования предыдущих субсидий и потенциал к росту **не учитываются**.

Министерство хочет перейти к **merit-based скорингу** — распределению субсидий на основе данных о производителях, а не по принципу очерёдности.

## Решение

AgriScore KZ — AI-система, которая заменяет принцип очереди на **data-driven ранжирование** с двумя компонентами:

### Композитный скоринг (60% ML + 40% Rules)

- **ML-компонент** — ансамбль XGBoost + LightGBM, обученный на 31,536 размеченных заявках с 30 инженерными признаками
- **Rule-based компонент** — экспертные правила на основе «Правил субсидирования развития племенного животноводства» (Приказ МСХ РК №108): приоритет типа субсидии, класс норматива, размер стада, региональный спрос, сезонность
- **Explainability** — SHAP-анализ каждого ML-фактора + разбивка rule-based компонентов + текстовое объяснение на русском языке

### Возможности системы

- **Скоринг заявителей** — каждая заявка получает балл от 0 до 100
- **Шорт-лист для комиссии** — автоматическое формирование списка лучших кандидатов с экспортом в CSV
- **What-If симулятор** — изменение параметров заявки в реальном времени с пересчётом балла
- **Загрузка новых заявок** — комиссия загружает CSV → получает ранжированный список
- **Аналитический дашборд** — визуализация по областям, направлениям, сравнение ML vs Rule компонентов

> AI помогает принимать решения, но **не заменяет эксперта**. Финальное решение всегда остаётся за комиссией.

## Данные

- **Источник**: Выгрузка из ИСС (subsidy.plem.kz) — 36,651 заявок на субсидии племенного животноводства за 2025 год
- **Области**: 18 областей Казахстана
- **Направления**: 9 направлений (скотоводство, птицеводство, овцеводство, коневодство, верблюдоводство и др.)
- **Типы субсидий**: 45+ видов субсидий
- **Target**: статус заявки (Одобрена/Исполнена vs Отклонена) — 31,536 размеченных записей

### Engineered Features (30 признаков)

| Группа | Признаки |
|--------|----------|
| Числовые (log) | Сумма, норматив, кол-во голов |
| Текстовые флаги | Импорт, племенная работа, селекция, молоко, мясо, птица, молодняк, покупка, корма |
| Категориальные | Область, район, направление, тип субсидии |
| Временные | Месяц, час, Q1 |
| Региональные агрегаты | Средняя сумма по области, доля одобренных, кол-во заявок, средняя по району |
| Ratios | Сумма/средняя по области, норматив/средний по направлению, головы/среднее по области |

## Explainability

Каждая заявка получает три уровня объяснения:

**1. Композитный балл** (0–100) = 60% ML + 40% Rule-based

**2. SHAP waterfall** — вклад каждого ML-фактора + разбивка rule-компонентов:

```
Итоговый балл: 90.2/100
  ML-компонент: 97.8  |  Rule-компонент: 78.7
  (60% ML + 40% Rules)

Положительные факторы:
  + Селекционная работа (+1.345)
  + Доля одобренных по области (+1.199)
  + Область (+0.393)
Факторы риска:
  - Месяц подачи (-0.208)
```

**3. Rule-based разбивка** — 6 нормативных компонентов с визуализацией:
- Тип субсидии (0–30): приоритет племенной работы
- Норматив (0–25): качество поголовья
- Размер стада (0–15): масштаб хозяйства
- Направление (0–10): приоритет отрасли
- Регион (0–10): региональный баланс
- Сезонность (0–10): оптимальность сроков

## Rule-based компонент

Основан на **«Правилах субсидирования развития племенного животноводства, повышения продуктивности и качества продукции животноводства»** (Приказ МСХ РК от 15.03.2019 №108):

- Приоритет типа субсидии: селекционная и племенная работа > приобретение поголовья > удешевление продукции > корма
- Высокий норматив = ценное племенное поголовье (импорт > отечественное)
- Крупные хозяйства — больше вклад в отрасль
- Региональный баланс — недообеспеченные регионы получают бонус
- Сезонность по типу животноводства

## Ограничения

- Датасет обезличен — нет ID производителя, нет агрегации истории по заявителю
- Модель обучена на данных 2025 года — для продакшена нужно периодическое дообучение
- Rule-based компонент основан на доступных данных; полная интеграция всех критериев Приложения 2 НПА требует дополнительных источников
- Система носит **рекомендательный характер** — финальное решение всегда за комиссией
